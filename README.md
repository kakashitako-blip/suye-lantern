# Suye ရဲ့ မီးပုံးကံစမ်းမဲ

သီတင်းကျွတ် lantern lucky draw. Tap one of nine lanterns, get a random amount of pocket money.

Single static `index.html`, no build step and no dependencies beyond Google Fonts. Serve it anywhere.

- Prize bands: 8% at 1–1.9 lakh, 72% at 2–4 lakh, 14% at 4.1–7 lakh, 3% at 7.1–9.9 lakh, 3% at exactly 1,000,000 Ks. Average ~361,000 Ks.
- One pick per browser, saved in `localStorage` so a refresh cannot re-roll it.
- Open with `#reset` on the URL to clear the saved pick and draw again.
